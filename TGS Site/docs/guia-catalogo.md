# Guia — Catálogo de produtos

## Fonte de dados

- **Arquivo**: `../products/products.js` (array `products`)
- **Assets**: `../midias/`

## Adicionar produto

Adicione um item no array `products` com:

- `id` (único)
- `name`
- `category` (`scripts` | `mods` | `graphics`)
- `price`
- `description`
- `features` (lista)
- `media` (imagens em `midias/...`)
